# Спрайты ночного боя

Размер клетки: **32x32**. Положите PNG с нужным именем в эту папку, и он заменит цветной кубик
(после добавления файла перезапустите `npm run dev`, если картинка не подхватилась сама).

| Файл | Что это | Рекомендуемый размер |
|---|---|---|
| grass.png, road.png, tree.png, rock.png, bunker.png | клетки карты (дерево и камень рисуются поверх травы, фон можно оставить прозрачным) | 32x32 |
| gate.png | ворота бункера | 32x32 |
| turret_basic.png, turret_rapid.png, turret_heavy.png | турели | 32x32 |
| barricade.png | баррикада на дороге | 32x32 |
| soldier_melee.png, soldier_ranged.png | солдаты (зелёный и жёлтый кубик) | до 32x32, центр в середине |
| enemy_grunt.png, enemy_spitter.png | враги (красный и фиолетовый кубик) | до 32x32, центр в середине |
| bullet.png | пуля (поворачивается по направлению полёта, рисуйте её «вправо») | любой, например 8x8 |
| fire.png | огонь от коктейля Молотова (растягивается под радиус) | 32x32 |
