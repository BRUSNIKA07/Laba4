# Last Outpost: Оборона Бункера

Монорепозиторий (npm workspaces). Готово: `shared/` (игровое ядро) и `client/` (Pip-Boy, PixiJS, этап 3c.1, соло).

## Запуск
```bash
npm install
npm run test:shared     # 49 тестов: роли, карта, приказы, волны, суточная экономика
npm run typecheck
npm run play            # консольная версия игры (см. ниже)
npm run dev             # Pip-Boy в браузере: http://localhost:5173
npm run build:shared    # tsup: ESM + CJS + .d.ts в shared/dist
```

## Что внутри shared/
| Папка | Назначение |
|---|---|
| `src/types/` | типы: роли, ресурсы, бункер, ночь, состояние партии, баланс |
| `src/protocol/` | события игры и сообщения клиент↔хост |
| `src/commands/` | парсер консоли, реестр команд (`registry.ts`), обработчики по ролям, легенда |
| `src/game/` | цикл `step()`, день/экономика, ночной бой, генератор карты, A*, вылазки, награды |
| `balance/*.json` | все числа баланса (читаются при запуске, пересборка не нужна) |
| `test/` | тесты (`node:test` через `tsx`) |

## Как пользоваться ядром
```ts
const b = parseBalance({ units, items, commands, waves, economy, rewards, sortie, map, squads, tactics }); // JSON из balance/
const state = createGame(b, { seed: 123, players: [{ id: 'p1', name: 'Ivan', roles: ['commander','farmer','manager','warden'] }] });
const res = executeCommand(state, b, 'p1', 'send 3 people to farmer'); // { ok, lines }
setInterval(() => { step(state, b); const events = drainEvents(state); }, 100); // 10 тиков в секунду
```
`state` — обычный JSON (его можно сохранять в БД и рассылать), все случайности идут от `seed`.

## Роли и команды
`commander`, `farmer`, `manager`, `warden`. Полный список: команда `help` в игре или `src/commands/registry.ts`.

## Консольная игра (проверка ядра и баланса)
```bash
npm run play                      # соло, реальное время
npm run play -- --speed 5         # время быстрее в 5 раз
npm run play -- --players 4       # четверо: /as anna, /as boris, /as clara, /as dima
```
Внутри игры: `help`, `status`, `/map` (карта ночи), `/speed 10`, `/quit`.

## Клиент (client/)
`npm run dev` из корня запускает Vite. Клиент берёт `shared` прямо из исходников и читает баланс из `shared/balance/*.json`
(при правке JSON страница перезагружается сама).
Горячие клавиши: Alt+1…5 — вкладки, Alt+L — легенда. Служебные команды консоли: `/speed 10` (ускорить время), `/clear`.
Ночью вкладка «Бункер» превращается в «Бой», а «Статистика» гаснет.

## Ночной бой (PixiJS) и спрайты
Бой рисует `client/src/night/NightRenderer.ts`. Клетка 32x32, пока цветные кубики. Чтобы подменить любой спрайт,
положите PNG в `client/src/assets/sprites/` (имена и размеры в README той папки). После `git pull`/обновления выполните `npm install` (добавлен pixi.js).

## Этап 3b.2.1: отряды и сетка

- Ночью `battle list` показывает живых бойцов, их позывные, отряды, секторы, HP и права управления.
- `grid off` и `grid on` — клиентские команды, меняющие видимость сетки A1–H8.
- Пропорции отрядов — `shared/balance/squads.json`. Позывные живых сохраняются между ночами.
- Карта создаётся один раз при старте партии. Дисковые сохранения ещё не реализованы.
- Для проверки быстро начните ночь командой `vote end`. В бою введите `battle list`, `grid off`, `grid on`.
- Команды перемещения `battle M01 G3`, камера, туман войны, лечение и остальные согласованные механики будут в следующих обновлениях.
- См. `DESIGN.md` и `CHANGELOG.md`.

### Этап 3b.2.2 — управление ночью
Начните ночь, введите `battle list`, затем используйте существующий позывной, например `battle M01 G3`, `battle M01 hold`, `battle M01 retreat`, `battle M01 auto`. В соло также доступны `battle all G3`, `battle all auto`, `battle farmer B2`, `battle ranged F5`. `battle squad` выбирает отряды ваших ролей. Пунктир указывает назначение. Настройки находятся в `shared/balance/tactics.json`. Графический клиент необходимо проверить в браузере.


## Этап 3c.1 — архитектурный план и суточная экономика

- Янтарный интерфейс Pip-Boy; карта днём слева, консоль справа. Колёсико — приближение, перетаскивание — перемещение, клик — карточка комнаты. Кнопка «СБРОС» возвращает обзор. В карточке нет кнопок строительства: команды нужно вводить в консоль.
- Чертёж фиксирован: шлюз, 12 помещений, коридор; жилой отсек, казарма, шлюз и производственные модули увеличиваются визуально при существующих улучшениях. Для производственного помещения показывается наибольший уровень его модуля. Лазарет и другие новые системы пока только на плане. Генераторная и ядро показаны построенными по согласованному проекту, не являются действующими системами.
- Каждый огонёк — один реальный человек в состоянии игры. Цвет зависит от ответственной роли. Свободные, строители и резерв смотрителя, а также незанятые farmer находятся в жилом отсеке. Новобранцы и армия в казарме. Люди вне бункера указаны отдельным счётчиком.
- Девять общих производственных модулей; стартовые — farm, lumber, quarry. Железо также производится в quarry; отдельный mine теперь означает железный модуль каменоломни. Для пустого модуля остаются прежние команды `build farm|lumber|quarry|mine <номер>`; `upgrade cell <номер>` увеличивает уровень до 3. `build farmroom` отключена, так как количество модулей фиксировано.
- День не заканчивается по времени. Только `vote end` строгим большинством (после выбора награды, если она предложена). Прогноз добычи фиксируется при переходе к ночи, ресурсы становятся доступными на рассвете. Голод по-прежнему считается перед ночью из доступных запасов. Ночная добыча врагов и предметы вылазок работают как прежде; ресурсы вылазок теперь также ждут рассвета.
- Нормы в `shared/balance/economy.json` теперь за игровой день (раньше за секунду; стартовые значения пересчитаны на старые 120 секунд). Временно ограничены суммарное время вылазок (120 секунд за день) и муштра (400 успешных команд за день), иначе бесконечный день позволил бы неограниченную прокачку. Это параметры баланса, не таймер окончания дня.
- Временно остаётся мгновенная работа прежних команд строительства/улучшения. Очередь строительства по игровым дням, полноценные уровни новых помещений, жизнеобеспечение и лазарет — будущие этапы. Ночные волны и боевые приказы не переписаны.

### Проверка дневного интерфейса

Запустите новую партию. Начальная теплица: 3 работника, 72 еды за день при текущем балансе. Для проверки огоньков:

```text
send 4 people to farmer
assign 3 workers to farm
assign 2 workers to quarry
assign 2 workers to lumber
send 1 people to manager
send 1 people to warden
cells
status
```

При клике на комнаты видны реальные назначения, добыча, цены и команды текущего ядра. `assign auto` возвращает автоматическое распределение. `build housing`, `build barracks` и `upgrade cell 1` (при наличии ресурсов) показывают рост помещения. Проверьте `vote end`, три волны и начисление добычи после ночи. Старые сохранения не предусмотрены: запускайте новую партию.

Проверка при подготовке архива: TypeScript shared и 49 тестов (временная компиляция в CommonJS и Node.js test runner), отдельно проверена TS-модель чертежа и соответствие количества точек населению. Установка Vue/Vite/PixiJS не удалась; полная проверка клиента, браузер и CSS-анимации требуют запуска у разработчика.
